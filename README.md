# GAMEHUB

Навчальний сайт про пошук напарників для кооперативних ігор. На сторінці є оголошення команд, спільноти, розклад подій, пакети участі та форма зворотного зв’язку.

[Відкрити GAMEHUB на GitHub Pages](https://andr1769.github.io/gamehub/)

## Запуск

Відкрийте `index.html` у браузері. Сайт використовує HTML, CSS і JavaScript. Збирання та встановлення залежностей не потрібні.

- `index.html` містить структуру й контент сторінки.
- `css/style.css` відповідає за оформлення, адаптивність і анімації.
- `img/`, `video/` та `fonts/` містять медіафайли і шрифт.
- `js/` містить керування фоновим відео та демонстраційною формою.

GitHub Pages публікує статичні файли з кореня гілки `main`. Форма перевіряє поля в браузері. Дані залишаються в поточній вкладці.

Шрифт Manrope поширюється за ліцензією, що міститься у `fonts/manrope-ofl.txt`. Назви та зображення ігор належать відповідним правовласникам.
